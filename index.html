Contexto

Problema identificado

Muitos estacionamentos ainda dependem de anotações manuais para registrar entradas, saídas, dados de veículos e valores cobrados.

Esse processo aumenta o risco de perda de informações, dificulta a conferência do histórico e torna a gestão diária mais lenta.

Dor principal

Falta de uma ferramenta simples para centralizar o controle operacional do estacionamento e acompanhar dados em tempo real.

Proposta

Solução desenvolvida

O VEX digitaliza o fluxo de gestão do estacionamento, conectando cadastro, histórico, tarifas e indicadores em uma única interface.

Cadastro de veículos

Registra placa, modelo, marca, cor, CPF do proprietário, tipo de veículo e tipo de estadia.

Controle de entradas

Mostra veículos em aberto e permite finalizar a saída com poucos cliques.

Configuração de tarifas

Permite cadastrar valores iniciais e adicionais por hora para diferentes tipos de veículo e estadia.

Implementação

Tecnologias utilizadas

O projeto combina frontend estático, API Node.js e banco de dados Supabase para entregar uma experiência funcional.

HTML CSS JavaScript Node.js Express Supabase Vercel
Arquitetura

Como a solução funciona

O usuário acessa a interface web, realiza login e utiliza as telas internas para cadastrar veículos, consultar históricos e configurar tarifas.

A API em Node.js processa as requisições e se comunica com o Supabase para autenticação e armazenamento dos dados.
