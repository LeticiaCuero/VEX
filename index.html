Automação simples para estacionamentos

Uma plataforma web para substituir registros em papel por check-in, check-out, cobrança configurável, histórico e indicadores operacionais.

Gestão digital do pátio

Dados para decisão

Contexto

Problema identificado

Estacionamentos privados de pequeno e médio porte ainda operam com registros manuais, controle visual do pátio e pouca auditoria sobre o tempo de permanência.

Esse modelo aumenta erros de transcrição, perda de informações, evasão de receita e dificulta a tomada de decisões com base em dados consolidados.

Dor principal

Falta de uma ferramenta acessível para centralizar entradas, saídas, cobranças, histórico e ocupação em tempo real.

Proposta

Solução desenvolvida

O VEX digitaliza o ciclo de permanência do veículo, da chegada à liquidação, organizando dados operacionais em uma interface simples para o gestor.

Registro de veículos

Armazena placa, modelo, marca, cor, dados do proprietário, tipo de veículo e horário de entrada.

Check-in e check-out

Controla veículos em aberto, calcula permanência e facilita a finalização do atendimento pelo operador.

Regras de cobrança

Permite configurar valores para clientes rotativos e mensalistas, com base no tipo de veículo e estadia.

Implementação

Tecnologias utilizadas

O projeto combina frontend web, API Node.js e Supabase para autenticação, persistência e consulta dos dados do estacionamento.

HTML CSS JavaScript Node.js Express Supabase Vercel
Arquitetura

Como a solução funciona

O administrador acessa o sistema pelo navegador, autentica sua conta e usa as telas internas para cadastrar veículos, consultar histórico, configurar tarifas e acompanhar indicadores.

A API processa as requisições e se comunica com o Supabase, mantendo os dados organizados e disponíveis para análise gerencial.

Demonstração

Apresentação do MVP

O MVP possui login, cadastro de veículos, finalização de entradas, histórico, dashboard, configuração de tarifas e integração com a API.
